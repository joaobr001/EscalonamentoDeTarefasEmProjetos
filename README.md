# Escalonamento de Tarefas em Projetos

Repositório para o trabalho da III Avaliação de Matemática Discreta – Teoria dos Grafos Aplicada à Computação.

## Tema
**Tema 3: Escalonamento de tarefas em projetos**
- Modelagem de dependências entre tarefas como um grafo direcionado acíclico (DAG).
- Definição da sequência de execução e caminho crítico.
- Algoritmos: Ordenação topológica, Caminho Crítico (CPM).
